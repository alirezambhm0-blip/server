■ گام‌های شما (به ترتیب — عجله نکن، هر قدم را بخوان):

  گام ۱) دو فایل eas.json و package.json را در پوشه wholesale-mobile جایگزین کنید
         (Replace). فایل OTA-GUIDE.md را کنار پروژه بگذارید.

  گام ۲) فایل OTA-GUIDE.md را باز کنید و از بخش «۳) راه‌اندازی یک‌بار» جلو بروید.
         خلاصه‌اش (برای اطمینان، جزئیات هر دستور در همان فایل هست):

           cd C:\Users\sam\Desktop\workspace-01\wholesale-mobile
           npm install -g eas-cli   ← نصب یک‌باره ابزار Expo (نام واقعی بسته: eas-cli)
           eas login                ← ورود با حساب Expo (قدم ۰ راهنما: ساخت حساب)
           eas init                 ← شناسه پروژه در app.json نوشته می‌شود
           eas update:configure     ← آدرس آپدیت با شناسه واقعی پر می‌شود
           eas build --profile preview --platform android   ← APK تستی (صبر ۱۵-۲۵ دقیقه)

  گام ۳) خروجی هر دستور را (موفق یا خطا) برایم بفرستید تا قدم‌به‌قدم با هم جلو برویم.
         مخصوصاً: اگر در وسط هر کدام سوال تعاملی پرسیده شد، متن سوال را بفرستید.
