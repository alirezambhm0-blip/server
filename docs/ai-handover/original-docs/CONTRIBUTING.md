# راهنمای مشارکت (CONTRIBUTING)

## اصل طلایی: تغییر حداقلی و محدوده‌دار

1. **تحلیل → تعیین scope دقیق → کوچک‌ترین تغییر امن → حفظ بقیه‌ی کد.**
2. کدِ کارکرده را عوض نکنید، مگر خودِ تسک یا یک وابستگیِ اثبات‌شده ایجاب کند.
3. کل فایل را بازنویسی نکنید وقتی فقط یک بخش کوچک نیاز به تغییر دارد؛ برای هر فایل اضافه‌شده باید توجیه وابستگی داشته باشید.
4. در شک «مرتبط بودن»، دست نزنید مگر با تحلیل وابستگی.
5. اگر تغییری توجیه‌پذیر نبود → revert.

## قبل از کدنویسی، اثر بالادست/پایین‌دست را بررسی کنید

- **موبایل:** صفحه/کامپوننت، state، فایل‌های `src/api/*` مصرف‌کننده
- **API:** کنترلر ← سرویس ← DTO/گارد؛ **سازگاری قرارداد خروجی با موبایل**
- **دیتابیس:** `prisma/schema.prisma` → بعد از هر تغییر: `npm run db:generate` (+ مایگریشن در صورت نیاز)
- **نقش‌ها:** هر endpoint جدید: گارد مناسب (`JwtAuthGuard`/`RolesGuard`) و رعایت جداسازی tenant
- **iOS/Android و قیود Expo:** بدون ماژول native خارج از Expo SDK مگر با بررسی EAS

## قوانین محصولی غیرقابل‌مذاکره

- هر `@Body()` = کلاس DTO با `class-validator`؛ رشته/آرایه خام ممنوع، mass assignment ممنوع.
- فیلدهای حساس پروفایل فقط با تایید ادمین (مسیر sensitive-change).
- انتقال وضعیت‌ها/شمارنده‌ها اتمیک و داخل تراکنش.
- سکرت‌ها هرگز hardcode نشوند؛ در فایل‌های نمونه از placeholder `‎<REPLACE_ME_XXX>‎` استفاده کنید.
- متن‌های رو به کاربر **فارسی**.
- هر تغییر معنادار در `RELEASE-PROGRESS.md` ثبت شود.

## سبک کامیت

```
<type>(scope): توضیح کوتاه
feat(phase5-3): improve documentation & DX
fix(orders): prevent duplicate stock decrement
```

typeها: `feat` (قابلیت)، `fix` (رفع باگ)، `perf`، `docs`، `refactor`، `chore`.

## چک‌لیست قبولی (DoD)

- [ ] فقط فایل‌های لازم تغییر کرده‌اند (هر فایل اضافی توجیه دارد)
- [ ] بک‌اند: `npx eslint src` = ۰ خطا، `npx tsc --noEmit` = ۰، `npm run build` = OK
- [ ] موبایل (در صورت تغییر): `npx tsc --noEmit` = ۰، `npm run lint` بدون خطای جدید
- [ ] قرارداد API با مصرف‌کننده موبایل سازگار است (grep اثبات)
- [ ] وابستگی جدید؟ `package.json` + `package-lock.json` **با هم** تحویل داده شده و نصب با `npm ci` راستی‌آزمایی شده
- [ ] مستندات/گزارش فاز به‌روزرسانی شده
