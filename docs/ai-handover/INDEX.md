## 🛠️ ۷. دستورهای آماده (grep recipes)

```bash
cd /path/to/project/src

# ── سرشماری ──
# تعداد endpoint
grep -rhE "^\s*@(Get|Post|Put|Patch|Delete)\(" --include=*.controller.ts wholesale-api/src | wc -l
# تعداد مدل / enum
grep -c '^model ' wholesale-api/prisma/schema.prisma
grep -c '^enum '  wholesale-api/prisma/schema.prisma
# تعداد route موبایل
find wholesale-mobile/app -type f | wc -l

# ── امنیت ──
# endpointهای بدون guard
grep -rn "@Controller" --include=*.controller.ts wholesale-api/src
grep -rn "@UseGuards\|@Roles" --include=*.controller.ts wholesale-api/src
# throw های خام
grep -rn "throw new Error(" --include=*.ts wholesale-api/src

# ── رویدادها ──
grep -rn "\.emit(\|@OnEvent" --include=*.ts wholesale-api/src

# ── «آیا این symbol اصلاً استفاده می‌شود؟» ──
grep -rn "<SymbolName>" wholesale-mobile/app wholesale-mobile/src
grep -rn "<SymbolName>" wholesale-api/src

# ── تاریخچه ──
git log --oneline --reverse        # ۵۹ کامیت
git show <commit>
git show HEAD:RELEASE-CHECKLIST.md  # بازیابی فایل غایب

# ── verify ──
cd wholesale-api    && npm test && npm run build && npx eslint "{src,apps,libs,test}/**/*.ts"
cd wholesale-mobile && npx tsc --noEmit && npx expo lint
```

⚠️ `cat` فایل‌های بزرگ را truncate می‌کند → `sed -n 'A,Bp'` یا `grep -n`
⚠️ **هرگز محتوای `.env` را چاپ نکنید** — فقط `sed 's/=.*/=<...>/'`
